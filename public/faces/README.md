# Лица персонажей

Лица загружаются из этой папки. Для персонажей используются PNG с точными именами:

- `patrick.png` — Патрик Джейн
- `negan.png` — Ниган
- `chester.png` — Честер
- `homelander.png` — Хоумлендер
- `saul.png` — Сол
- `walt.png` — Уолтер
- `hector.png` — Гектор Саламанка
- `salamanca.png` — братья Саламанка, которых вызывает Гектор
- `stormtrooper.png` — Табтрупер, если файл содержит прозрачный портрет шлема;
  при непрозрачном исходнике игра использует прозрачный `trooper.png`.

В меню для Табтрупера используется `trooper-menu.png` — копия `trooper.png` с
обрезанными прозрачными полями. Это исправляет визуально маленький шлем, не
меняя исходное изображение, которое использует игра. При замене шлема следует
обновить обе версии.

Изображения загружаются автоматически по адресам `/faces/<имя>.png`.
После замены файла нужна повторная сборка и публикация. Если файл недоступен,
игра использует старый удалённый портрет (если он доступен) или нейтральную
пиксельную заглушку.
