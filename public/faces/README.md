# Лица персонажей

Лица загружаются из этой папки. Для персонажей используются PNG с точными именами:

- `patrick.png` — Патрик Джейн
- `negan.png` — Ниган
- `chester.png` — Честер
- `homelander.png` — Хоумлендер
- `saul.png` — Сол
- `walt.png` — Уолтер
- `stormtrooper.png` — Штурмовик (шлем; при добитии Ниганом шлем трескается и открывается лицо)

Изображения загружаются автоматически по адресам `/faces/<имя>.png`.
После замены файла нужна повторная сборка и публикация. Если файл недоступен,
игра использует старый удалённый портрет (если он доступен) или нейтральную
пиксельную заглушку.
