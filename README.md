# PIBS-DUMMY-FURY

Пиксельная арена с автономными боями. Запуск локально: `npm install`, затем
`npm run dev`. Проверки: `npm test`, `npm run build`, `npx tsc --noEmit`.

## Камера

Кнопки «Камера» справа поднимают и опускают вид или возвращают его к полу.
Также можно использовать колесо мыши, клавиши ↑/↓ (Page Up/Down) или перетащить
арену мышью/пальцем. Обычное касание или клик добавляет бойца.

Чтобы исключить случайный спавн при перемещении, включите справа
«КАМЕРА → ДВИГАТЬ». В этом режиме даже короткие касания арены не создают
бойцов; перетаскивание двигает камеру, а кнопки спавна продолжают работать.
Выключите режим, чтобы снова добавлять бойцов касанием арены.

## Лица

Портреты загружаются из `public/faces/`. Точные имена перечислены в
[`public/faces/README.md`](public/faces/README.md). Если портрет недоступен,
игра использует старый удалённый портрет или нейтральную пиксельную заглушку.
