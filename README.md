# PIBS-DUMMY-FURY

Пиксельная песочница с автономными бойцами. Запуск локально: `npm install`,
затем `npm run dev`. Проверки: `npm test`, `npm run build`, `npx tsc --noEmit`.

## Управление

- Откройте меню у левого края экрана. Во вкладке **Персонажи** выберите героя;
  меню закроется, а выбор сохранится для следующих размещений. Вкладки
  **Предметы** и **Настройки** пока пусты.
- Щёлкните левой кнопкой мыши или коснитесь свободного места на арене, чтобы
  добавить выбранного персонажа. Выше мостика он приземлится на мостик, ниже —
  на пол арены. Изначально арена пуста; автоматического спавна нет.
- Перетаскивайте **правой** кнопкой мыши вверх или вниз либо используйте колесо
  мыши для вертикального перемещения камеры. Левая кнопка камеру не двигает.
- На сенсорном экране перетащите арену пальцем, чтобы переместить камеру;
  короткое неподвижное касание размещает бойца. Перетаскивание и жесты с
  несколькими пальцами не создают случайных бойцов. Список в меню прокручивается,
  если экран невысокий.
- Удерживайте **Shift**, чтобы первый живой боец присел. Также камеру можно
  двигать клавишами ↑/↓ и Page Up/Down; Home возвращает её к полу.
- Кнопка в правом верхнем углу ставит симуляцию и звук на паузу; повторное
  нажатие продолжает игру. Во время паузы размещение и движение камеры отключены,
  но меню и кнопки очистки работают.

Кнопки внизу меню:

- **Очистить всё** — убрать персонажей, тела, предметы и кровь, не меняя карту.
- **Убрать тела** — убрать погибших, их фрагменты и брошенное оружие.
- **Очистить кровь** — убрать лужи, капли и пятна. Раны при этом не лечатся,
  поэтому кровь может появиться снова.
- **Восстановить карту** — починить оборванные светильники и убрать трещины и
  следы повреждений карты; персонажи и кровь останутся на месте.

В одиночестве персонажи могут ходить, стоять, бегать, приседать и прыгать;
при встрече с противником они сражаются самостоятельно. Бойцы на мостике не
выбирают цели внизу, могут вернуться по канату, а опасные столкновения с
падением с мостика случаются редко. Текстовых реплик у персонажей нет.

## Ресурсы

Портреты загружаются из `public/faces/`; точные имена перечислены в
[`public/faces/README.md`](public/faces/README.md). Для меню у шлема Табтрупера
обрезаны прозрачные поля, исходный игровой файл не изменён. Если файл портрета
недоступен, игра использует запасной портрет или нейтральную пиксельную заглушку.

В исходной ветке были только `menu.png` и `close.png`. Пока оригиналы не
добавлены, в `public/icons/` используются локальные временные пиксельные
`chars.png`, `entities.png`, `settings.png`, `pause.png` и `play.png`; их можно
заменить файлами с теми же именами. Пиксельный шрифт Press Start 2P включён
локально; его лицензия находится в `public/fonts/OFL-PressStart2P.txt`.
